# 🌍 World Clock App

A simple web application that displays the current time in multiple countries and detects the user’s location.

## 🚀 Live Demo  
https://raspberryworldclock.netlify.app  

## 🛠️ Technologies Used  
- HTML  
- CSS  
- JavaScript  

## ✨ Features  
- Displays current time in different world cities  
- Detects user’s local time  
- Clean and responsive interface  

## 📌 Purpose  
Built to practice JavaScript date/time handling and DOM manipulation.
